# Портфолио таргетолога

Статичный сайт для GitHub Pages: без сборки и зависимостей.

## Как опубликовать
1. Создайте репозиторий на GitHub (например, `portfolio`).
2. Загрузите все файлы из этой папки в корень репозитория (Add file → Upload files).
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Что проверить
- `js/cases.js`, объект `SITE`: имя, контакты, тексты, ниши, навыки, этапы работы. Instagram пустой — кнопки Instagram скрыты, пока не вставите ссылку.
- `img/photo.jpg` (первый экран) и `img/photo-2.jpg` (блок «Обо мне»).
- В кейсах: название «Онлайн-проект в Telegram» и годы у некоторых кейсов уточните. Пометка `agency: true` ставит на карточку «в агентстве».

## Структура
- `index.html`: главная (первый экран с карточкой цифр, бегущая строка, опыт, площадки, кейсы с фильтрами)
- `case.html`: страница кейса, открывается как `case.html?case=choupette`
- `css/style.css`: стили, тёмная тема по умолчанию и светлая по кнопке
- `js/cases.js`: все тексты и данные кейсов
- `js/common.js`, `js/main.js`, `js/case.js`: логика страниц

## Как добавить кейс
Скопируйте один блок `{ id: ..., accent: ..., ... }` в массиве `CASES` и поменяйте значения. `accent` — цвет полоски и подсветки карточки, `category` — id ниши из `NICHES` для фильтра.
